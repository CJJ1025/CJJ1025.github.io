> 手速就是分数。下面是算法竞赛里约定俗成的简写，统一使用能省下大量敲键盘的时间。

## 基础

- `calc` = calculate：计算、递归求解
- `sol` = solve：主求解函数
- `chk` = check：校验、判断合法性
- `qry` = query：查询
- `upd` = update：更新
- `cnt` = count：计数器
- `res` = result：答案、结果
- `ans` = answer：最终答案（最常用）
- `tmp` = temporary：临时变量
- `lst` = last：上一个、最后
- `nxt` = next：下一个
- `pre` = previous：前驱
- `cur` = current：当前
- `tot` = total：总和、总数量

## 图论

- `u / v`：节点（约定俗成，不是缩写）
- `fa` = father：父节点（并查集、树）
- `dep` = depth：深度
- `dis` = distance：距离
- `vis` = visit：访问标记数组
- `edg` = edge：边
- `to`：边指向的点
- `siz` = size：子树大小
- `rt` = root：根
- `dfn`：dfs 序（固定缩写）
- `low`：tarjan 里 low 值（固定缩写）

## 字符串

- `s`：字符串本体
- `len` = length：长度
- `pos` = position：位置
- `str` = string：字符串
- `sub` = substring：子串

## 动态规划

- `dp`：dynamic programming
- `val` = value：权值、数值
- `w` = weight：权重
- `cost`：花费
- `mx` = max：最大值
- `mn` = min：最小值

## 数据结构

- `pq`：priority_queue 优先队列
- `seg` = segment：线段树
- `bit`：树状数组（Binary Indexed Tree）
- `sta` = stack：栈
- `que` = queue：队列

## 其他

- `id`：编号
- `lim` = limit：上限
- `opt` = optimal：最优
- `seg` = segment：区间、线段
- `l` / `r`：左右端点
- `lb` = lowbit
- `g`：graph，存图邻接表
