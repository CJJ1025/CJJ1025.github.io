## 专栏说明

- **目标读者**：跟我一样刚入门 STM32 嵌入式开发的同学，主要跟随**江科大 / 江协科技 STM32 入门教程**的进度。
- **代码风格**：所有示例都用 **STM32F103 标准外设库（固件库 v3.5）**，对应江科大那种「寄存器 + 库函数」混讲的风格。HAL 库 / CubeMX 的 API 名不同，但物理意义可以对照。
- **阅读顺序**：建议**从 01 开始按顺序看**，每篇都假设你已经看过前面的内容。

## 通用约定

| 项 | 约定 |
| --- | --- |
| 芯片型号 | STM32F103C8T6（江科大最小系统板） |
| 库 | STM32F10x 标准外设库 v3.5 |
| 编译器 | Keil MDK-ARM 5.x |
| 时钟 | 默认 72 MHz 主频 |
| LED 电平约定 | 板载 PC13 LED 是低电平点亮（个别板子不同，**先查原理图**） |

## 准备知识（不需要全懂，先有个印象就行）

- C 语言基本语法（`if` / `while` / `&` 取地址）；
- 二进制与位运算（`&` / `|` / `~` / `<<` / `>>`）；
- 一点点数字电路常识（高电平 / 低电平、上拉电阻、开漏输出）。

如果某个 API 不熟，先回 01 那篇把「开时钟 → 配结构体 → 调函数」的三件套过一遍；其它外设（USART、SPI、I²C、TIM、ADC）套路都一样。
